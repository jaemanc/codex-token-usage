# Support — Codex Token Usage

For bugs, installation help, or privacy questions, open a [GitHub issue](https://github.com/jaemanc/codex-token-usage/issues). Do not include private prompts, session logs, or TSV files in a public issue. If a report is needed, remove sensitive content first.

The plugin requires Codex desktop local execution, Python 3.9 or newer, and local Codex session logs. It reads the log values available on your machine; missing or changed log fields may show as unavailable.
