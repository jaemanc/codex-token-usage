# Privacy Policy — Codex Token Usage

Last updated: November 4, 2026.

Codex Token Usage reads Codex session logs on your computer when you ask it for a report. These logs can contain your prompt text, timestamps, token counts, and recorded usage-limit percentages. The script uses that information to display a report and, when run, writes a TSV file to the output path you choose or the current directory by default.

The script makes no network requests. The plugin developer does not receive or store your logs, prompts, or TSV files. If you invoke the skill in a Codex conversation, the report may be included in that conversation and handled under your OpenAI account settings and OpenAI's applicable policies.

The TSV remains on your computer until you delete it. It may contain full prompt text, so store and share it carefully. You can remove it at any time. The script does not delete or modify the original Codex session logs.

This policy covers the plugin itself, not Codex or OpenAI's processing of your conversations. For questions, see [Support](SUPPORT.md).
